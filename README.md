# triple-h-hugo-template
Historical theme repository for hannah-www.

## Current maintenance

The website now maintains its theme directly in
[hannah-www/themes/triple-h-hugo-template](https://github.com/hannahhenderson/hannah-www/tree/master/themes/triple-h-hugo-template).
That directory is the authoritative home for future website theme changes.
The website does not fetch or automatically sync this separate repository.

Please submit changes for Hannah's website in `hannah-www`, alongside any
related website changes. The website repository is private; its source is
available only to authorized collaborators. This repository remains available
for its history and existing users.

See [website PR #27](https://github.com/hannahhenderson/hannah-www/pull/27)
for the setup documentation cleanup (repository access required).

This project is based on [kross-hugo-portfolio-template](https://github.com/themefisher/kross-hugo-portfolio-template) with several design elements incorporated from [hugo-theme-cleanwhite](https://github.com/zhaohuabing/hugo-theme-cleanwhite).
